              Priorité de lecture

              Un fichier peut porter la même information dans plusieurs formats : le premier format qui en contient l'emporte (pour les mots-clés, c'est lui qui alimente l'arborescence). Tous sont écrits. Glissez les lignes pour réordonner ; le nouvel ordre s'applique à la prochaine relecture de la collection.

                Visages

                Relisez la collection pour lire les visages des photos déjà cataloguées.

                Modèle

                Installation sans Internet

                Téléchargez ces fichiers sur un autre ordinateur, placez-les dans un même dossier, puis choisissez ce dossier avec « Installer depuis un dossier… ». Chaque fichier est vérifié par sa somme SHA-256.
